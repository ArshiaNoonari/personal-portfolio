A responsive, animated personal portfolio built with **pure HTML and CSS**. There is no JavaScript anywhere in this project; every animation and effect is done with CSS.

A responsive, animated personal portfolio built with **pure HTML and CSS**. There is no JavaScript anywhere in this project; every animation and effect is done with CSS.

**Live site:** [https://personal-portfolio-arshia8.vercel.app/](#)

---

## About

I'm a second-year BS Information Technology student at Sindh Madressatul Islam University (SMIU), Karachi, and a frontend developer in the making. This portfolio started as my CodeAlpha internship task and was rebuilt as an academy assignment with a new design, animations, more projects and a mobile-first layout.

## Features

- **Pure HTML and CSS:** no JavaScript, frameworks or libraries
- **Dark purple theme** with a gradient accent, using the Syne and Inter fonts
- **Fully responsive:** tested for phones, tablets and desktops
- **CSS-only animations:**
  - Staggered hero entrance and a typing role line
  - A self-typing code window and twinkling star background
  - Scrolling skills marquee
  - Scroll-driven reveals, stat count-up and a scroll progress bar
  - Hover effects on cards, including a spinning gradient border
- **Accessible:** semantic HTML, visible focus states, image alt text and support for `prefers-reduced-motion`
- **Clean, commented CSS** organised into numbered sections

## Sections

1. **Hero:** introduction and call-to-action buttons
2. **About:** short bio and quick stats
3. **Skills:** frontend, design-to-code, tools and other languages
4. **Projects:** 8 projects with screenshots, live demos and source code
5. **Experience:** internship timeline
6. **Contact:** email, GitHub and LinkedIn

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/ArshiaNoonari/codeAplha-task-2.git
   ```
2. Open the folder and double-click `index.html`, or open it with Live Server in VS Code.

No install or build step is needed.

## Browser support

The site works in all modern browsers. Scroll-driven effects (reveal on scroll, stat count-up and the progress bar) use the CSS `animation-timeline` feature, which is available in recent versions of Chrome, Edge and Safari. In older browsers the content simply appears without those effects.
